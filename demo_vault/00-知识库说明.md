# VibeAtlas 合成演示知识库

本目录只包含为公开演示生成的合成内容，不包含个人笔记、工作资料、原始截图或附件。它用于验证 `--vault-root` 隔离和知识点图谱接口。

## 演示规则

- 笔记之间使用无路径的 `[[文件名]]` 双链。
- 收录事务同步维护 [[01-知识库目录]] 与 [[02-更新流水账]]。
- 每份材料都要写成一篇或多篇知识笔记，并按来源和按知识点更新目录；流水账只追加唯一一行。
- 演示数据不代表真实业务结论，也不应作为生产知识库使用。
