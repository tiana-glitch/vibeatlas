# 知识库说明

这是 {{PROFESSION}} 的工作经验知识库，用于长期复盘、项目沉淀、面试准备和简历写作。主入口是 [[01-知识库目录]]，所有变更记录在 [[02-更新流水账]]。

## 两条不可破例的规则

1. 笔记里提到另一篇笔记时，只能用 `[[文件名]]` 这种两个方括号的写法。不得在双链里写文件夹或斜杠，不得用带路径的 Markdown 链接代替。
2. 每丢进来一份材料，必须同时做完三件事才算完成：写成一篇或多篇知识笔记、更新目录、在流水账里记唯一一行。一份文档即使拆成多个知识点，也只算一次收录；同一次涉及的全部知识笔记写在同一行，不得拆成多行。

## 维护约定

- 所有知识笔记的 basename 必须唯一；原始来源文件也使用唯一文件名，保证 `[[文件名]]` 能准确连成知识网络。
- 新材料先放进 [[待整理内容]]，整理后移动到对应主题目录。
- 原始文档原样保存在 `07-素材附件/原始资料/`。这里的 Markdown 是证据而非知识笔记，不修改其内部链接来迎合知识库规则。
- 一份文档包含多个可独立复用的结论、方法、决策、教训或定义时，每个知识点单独写入 `08-知识点/`，并回链带扩展名的来源文件。
- 项目事实、指标、日期和个人贡献必须有依据；没有依据时标记“待补充”或“待核验”。
- 公司内部材料默认私密；写入公开简历前先脱敏。
- 新知识优先合并到已有长期笔记，避免堆积孤立摘要。
- 冲突信息保留历史并标记“有争议”或“已过时”，不静默覆盖。

## 完成标准

一次收录只有在以下三项都存在时才完成：

- 一篇或多篇对应知识笔记；
- [[01-知识库目录]] 中按来源和按知识点维护的无路径双链；
- [[02-更新流水账]] 中包含全部当次笔记的唯一一行记录。
